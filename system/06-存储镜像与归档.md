### vhdx 只增不减

删除文件不会自动缩小 vhdx。回收：

```powershell
wsl --shutdown
wsl --manage Ubuntu-24.04 --set-sparse true
# 或 diskpart 挂载 vhdx 后 compact vdisk
```

`sparseVhd=true` 已开，但需要一次离线整理才会明显缩小。

## 7. 清理建议

安全、按收益排序：

```bash
# 1. 构建缓存 8.8 GB（不影响运行镜像）
docker builder prune -f

# 2. 一次性构建测试容器
docker rm sad_montalcini

# 3. 演示面板（镜像 593 MB + 两个容器）
docker rm -f clash-proxy-demo clash-proxy-demo.bak
docker rmi clash-proxy-manager:latest

# 4. 未使用镜像（先看清单再删）
docker image prune -a
```

不要误删：

| 对象 | 原因 |
|---|---|
| `goofish-hardware-sniper:local` | 唯一在跑的应用 |
| `postgres/mysql/mongo/forgejo/mobsf/mitmproxy/portainer` | x01 服务栈 |
| `o2a-*` / `warp-pool*` | 可能还要做代理池实验 |
| `shardx-team-data` 卷 | 应用数据 |
