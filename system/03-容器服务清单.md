## 2. infra 约定

| 约定 | 内容 |
|---|---|
| 分层 | `net / data / dev / sec / ops` |
| 模块 | 一个目录 = 一个 compose 项目 |
| 命名 | `x01-<layer>-<module>[-role]` |
| 标签 | `x01.layer`、`x01.module`、`x01.role` |
| 目录内容 | `compose.yaml`、`.env`（600）、`README.md`、`data/` |
| 例外 | `net/mihomo` 是原生 systemd，不是容器 |
| 日志 | 每个 compose 都限制 `json-file`，`max-size=20m`、`max-file=3` |
| 网络 | data 层共用 `x01-data-net`（172.23.0.0/16）；其余各自默认桥 |

统一 CLI：

```bash
~/infra/bin/x01 ls        # 列出模块

~/infra/bin/x01 up   dev/forgejo
~/infra/bin/x01 down dev/forgejo
~/infra/bin/x01 restart dev/forgejo
~/infra/bin/x01 logs dev/forgejo -f
~/infra/bin/x01 path dev/forgejo
~/infra/bin/x01 net       # 网络体检
```

## 10. 启停策略

| 场景 | 行为 |
|---|---|
| 手动 `docker stop` | `unless-stopped` **不会**在 Docker 重启后拉起 |
| `wsl --shutdown` | 运行中的 `unless-stopped` 容器下次自动恢复 |
| `restart: no` | 永远不自动起（clash demo、Sub-Store） |
| 冷启动 | dockerd 清理陈旧 sandbox 约 3–4 分钟，再逐个起容器 |
| Postgres 强停后 | 约 4 分钟 fsync 恢复，`pg_isready` 先拒绝后接受 |
